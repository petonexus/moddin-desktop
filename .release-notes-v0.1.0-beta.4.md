# v0.1.0-beta.4 — plain language, no more "capability"

Small follow-up to beta.3. The AI dialog and the prompt it generates still used the word **"capability"** in places the user reads — chips like "Melhorar uma capability", the mode description, the prompt itself ("The user installed a Moddin capability …"). Nobody outside the Moddin code knows what that word means; the rest of the app already calls these things **mods**.

> ⚠️ Still a **beta**. It runs real installs, real registry writes and real process kills. Read the [User Guide](https://github.com/petonexus/moddin-desktop/blob/main/docs/USER-GUIDE.md) before applying anything new.

---

## What changed

- **AI dialog chips**: `Melhorar uma capability` → `Melhorar um mod`; `Criar nova capability` → `Criar um mod novo`.
- **Mode descriptions**: `Editar uma capability existente com IA` → `Melhorar um mod que você já tem com a IA`; `Adicionar uma nova capability com IA` → `Criar um mod novo com a IA`.
- **Save confirmations**: `Capability {id} salva` → `Mod {id} salvo`; the body line no longer says "a nova capability aparece".
- **"Why this?" tooltip**: `Vale a pena instalar essa capability?` → `Vale a pena instalar este mod?`.
- **The prompt itself**: `The user installed a Moddin capability (id: …)` → `The user installed a Moddin mod for … (internal id in the catalog file: …)`. The prompt also adds one sentence explaining that each mod lives under a `modules:` list in the YAML, so the AI knows the schema without the user needing to learn the term.
- **Fallback notice**: `Sem backend Rust ainda — usando o template local` → `O Moddin ainda não monta o prompt sozinho — este texto é gerado localmente`. Same idea in English and Spanish.
- **idtech engine preset description**: same terminology fix in the catalog text.
- Same edits in English and Spanish.

Nothing about the install, the installer size, the signing key, or the catalog changes in this release. If you already installed beta.3, you can install this on top — it replaces the same files.

## Install (Windows 10 / 11 x64)

Download the installer below and run it. It puts Moddin in `%LOCALAPPDATA%\Programs\Moddin Desktop` and adds an uninstaller to **Settings → Apps**.

- **Installer:** `Moddin.Desktop_0.1.0_x64-setup.exe` (attached below) — 3.6 MB (NSIS, installs per-user, no admin required)
- **SHA-256:** `A732356DF3FA693F9B35B0DA0851CA95BA082A79A9D569B1456966C71E4467C3`
- WebView2 Runtime is required (pre-installed on Windows 11; Windows 10 installs it automatically if missing).
