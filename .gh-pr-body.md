This PR transfers the repo identity to `petonexus/moddin-desktop` and lays down the scope, engine-preset, and module-work plumbing the Moddin Desktop app needs as it grows.

### Highlights

- **Identity transfer** (already applied via the GitHub API): the repo was renamed from `marcoasjunior/moddin` to `petonexus/moddin-desktop`. All User-Agent strings, package metadata, Cargo metadata, Tauri identifier, README badges, and documentation links now point at the new home.
- **`docs/SCOPE.md`** codifies the three layers (catalog / reusable module / standalone tool), decision rules for adding games, modules, and tools, the engine-to-module mapping, VR/DLSS coverage, the target repository layout, and explicit anti-patterns.
- **`tools/README.md`** is the contract every `tools/<topic>/` package must follow (README + MODDIN-AGENT-CONTEXT + .cmd + scripts/<core>.ps1 + .gitignore). The Elden Ring baseline package was brought in line with that contract.
- **Engine presets** (`src/catalog/engines/{unreal5,redengine,re-engine}.yaml`) merge their module list into each game at load time. Per-game modules win on id collisions, so existing recipes can override defaults without touching the preset. Catalog loader fails fast when a preset reference is missing.
- **Trait `Module`** in `src-tauri/src/module.rs` is the lifecycle contract every native capability should eventually implement. `preview`, `apply`, `verify`, `remove`, `update_check` are async (matching the existing `#[tauri::command]` shape); `rollback` stays sync and delegates to the transaction store.
- **Pilot `OfxrModule`** demonstrates the incremental adoption pattern: the wrapper implements the trait by short-circuiting to a stub preview while the catalog config flows through `ModuleContext`. The production `ofxr.rs` is untouched.
- **`reshade.rs`** is a real ReShade host installer (download + SHA-256 + extract + multi-file transaction + marker + rollback). UE4SS, BepInEx, REFramework ship as documented stubs that return `not implemented` and point to `docs/MODULES.md`.
- **`docs/MODULES.md`** is the design doc for ReShade, UE4SS, BepInEx, and REFramework: upstream feeds, config surfaces, state markers, safety rules, and the per-module adoption path to the `Module` trait.
- **`docs/MERGE-NOTES.md`** explains how to reconcile the local WIP stash (catalogs for dawnwalker / stalker-2 / dead-island-2, hardening in `steam.rs` / `inspection.rs`, OpenXR feature work) with this branch.
