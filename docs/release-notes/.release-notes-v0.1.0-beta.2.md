# v0.1.0-beta.2 — clearer interface, no more console flashes

Second public beta. The headline is a redesigned interface that explains itself in plain language, plus two fixes every Windows user will notice.

> ⚠️ Still a **beta**. It runs real installs, real registry writes and real process kills. Read the [User Guide](https://github.com/petonexus/moddin-desktop/blob/main/docs/USER-GUIDE.md) before applying anything new.

---

## Fixes you will notice

- **No more console windows popping up.** While Moddin was open, a `cmd` window kept flashing every few seconds. Moddin checks whether your game is running, and each check opened a visible console. All background helpers now run hidden, and the check pauses while Moddin is minimised.
- **The app opens again.** An invalid entry in the STALKER 2 catalog file made the whole window start blank. Fixed.

## A redesigned interface

- **Everything in one sidebar.** Library, History and a Tools group (VR system, Community, Activity). The floating buttons that covered the screen are gone.
- **A game page you can read top to bottom.** Game name, a progress bar ("1 of 6 mods active"), a notice when the game is running, your mods grouped by category, and technical info tucked away at the end.
- **Simpler mod cards.** Each card shows one status (Active, Not installed, Needs attention…) and one main button. If something fails, the card says what. Checklists, updates and advanced options live under "Details".
- **Consistent dialogs.** Every install or launch preview answers the same questions in the same order: what Moddin will do, what to watch out for, and a reminder that you can undo it.
- **History instead of "Transactions".** It uses game and mod names instead of internal ids, has an "Active only" filter, and gives you one-click undo.
- **Plain language in Portuguese, English and Spanish.** Written for players, not engineers.
- **Keyboard friendly.** Esc closes any dialog, and focus stays inside the open dialog.

## Also new since beta.1

- **Add mods with an AI assistant.** The new [`moddin-agent`](https://github.com/petonexus/moddin-desktop/tree/main/moddin-agent) MCP server lets an AI assistant draft capability recipes. It can only write recipe files; installing, removing and undoing still happen in Moddin, with the usual preview.
- **Engine presets for every supported game** (Unreal 5, REDengine, RE Engine, id Tech, Unity). Each game now gets a sensible default mod list.
- **Groundwork, not yet in the interface:** GOG game detection, a library scan cache, PCGamingWiki lookups, restore points (snapshots) and import/export of install profiles. The backend pieces are in; the screens for them come next.

## Install (Windows 10 / 11 x64)

Download the installer below and run it. It puts Moddin in `Program Files\Moddin Desktop` and adds an uninstaller to **Settings → Apps**.

- **Installer:** [Moddin.Desktop_0.1.0_x64-setup.exe](https://github.com/petonexus/moddin-desktop/releases/download/v0.1.0-beta.2/Moddin.Desktop_0.1.0_x64-setup.exe) — 3.6 MB (NSIS, installs per-user, no admin required)
- **SHA-256:** `375F89DCA065C8C5134EE82C52C856975661252C2FFB35682C2BB2DBB427ED75`
- WebView2 Runtime is required (pre-installed on Windows 11; Windows 10 installs it automatically if missing).

### Or build from source

If you prefer to compile it yourself, you need `Node.js 20+`, `Rust stable (MSVC)` and the Visual Studio C++ build tools.

```powershell
git clone https://github.com/petonexus/moddin-desktop.git
cd moddin-desktop
git checkout v0.1.0-beta.2
npm ci
npm run tauri build
```

The installer ends up in `src-tauri\target\release\bundle\nsis\`, the standalone exe in `src-tauri\target\release\moddin-desktop.exe`.

## What to test

- [ ] No console window appears while Moddin is open or while a game is running
- [ ] Steam and Epic games show up; "With mods" lists the supported ones
- [ ] Opening a game shows the right status on each mod card
- [ ] Installing a mod shows the preview, applies, and appears in History
- [ ] Undo in History restores the original files
- [ ] With the game running, install/remove buttons are blocked and the notice explains why
- [ ] VR system panel lists your VR apps (SteamVR, Meta, Virtual Desktop…)
- [ ] Switching language in the sidebar updates the whole interface

Found a problem? Open an [issue](https://github.com/petonexus/moddin-desktop/issues) with your Windows version, the steps to reproduce and an excerpt from **Activity** in the sidebar.

---

## Known limitations

- Some preview text that comes from the backend (the "what Moddin will do" list) and the recommended VR settings are still in English only.
- GOG games are detected by the backend but do not appear in the library yet.
- OFXR Bridge is **experimental** and may cause artifacts or crashes depending on game, GPU and VR runtime. Every change can be undone from History.
- Anti-cheat is never bypassed.
