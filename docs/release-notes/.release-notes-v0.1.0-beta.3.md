# v0.1.0-beta.3 — AI surface that explains itself, errors that tell you what to do

Third public beta. The headline is a redesigned AI surface (one primary action, plain language, no cryptic backend errors), friendly error messages across the panels that touch your system, and a switch to a smaller, per-user installer. Plus a security refresh of the community catalog signing key.

> ⚠️ Still a **beta**. It runs real installs, real registry writes and real process kills. Read the [User Guide](https://github.com/petonexus/moddin-desktop/blob/main/docs/USER-GUIDE.md) before applying anything new.

---

## What you will notice right away

- **One AI button that does the right thing.** The top-bar "Pedir ajuda à IA" entry is now a quiet chip next to the main action. Click it and you get a single big "Gerar prompt" button — not five equal-weight buttons competing for attention.
- **Errors that tell you what to do.** When the Community, VR or Activity panels hit a problem, you see a one-line title, a sentence explaining what to try, and the technical detail tucked under a disclosure for power users. No more raw "Verification equation was not satisfied".
- **A smaller, per-user installer.** We dropped the MSI in favour of NSIS (3.6 MB instead of 5.6 MB). It installs under your user account, no administrator prompt.

## The AI surface, redone

- **AiAssistantDialog**: one primary CTA card with a gradient, four secondary chips to switch between Recomendar / Diagnosticar / Melhorar / Criar, an "advanced" disclosure for verbosity, and a sticky footer with the action you actually want on the right.
- **JS-side prompt template**: even without the Rust `capability_authoring` backend, the dialog always produces a usable prompt. You never see "Command build_author_prompt not found" again.
- **Library error callout**: when the library scan fails, the red banner now carries an "Explicar este erro com IA" button that hands the error straight to the assistant.
- **Top-bar menu**: the AI menu demoted from a split-button to a discrete chip, so it stops fighting with "Jogar em VR" for visual attention.
- **Game suggestions banner**: the "Não sabe por onde começar?" callout now has a clear primary ("Pedir sugestões à IA") and a muted secondary ("Auditar meu setup"). One glance, one choice.

## Friendly errors (Microsoft HAI Guidelines G1 + G2)

Three panels translate raw backend errors into a clear title, an actionable "why" line, and a collapsible raw detail:

- **Community** — signature / network / catalog-missing / generic. With the rotated catalog key, the most common "Verification equation" error stops happening.
- **VR system** — UAC denied / generic. Tells you to retry and click "Yes" on the Windows prompt.
- **Activity log** — file locked (antivirus, editor, backup tool) / missing / disk full / generic. Suggests what to close or free up.

All in Portuguese, English and Spanish.

## Security

- **Community catalog signing key rotated.** The old key (`e247ca4981f22245`) was superseded by a new one (`d489a3a0be894b19`). Older Moddin installs need to update to validate the new catalog.

## Fixes

- **No more red "Command build_author_prompt not found" banner.** Handled in JS with a local template.
- **STALKER 2 catalog** now lists OptiScaler as **proven** and ReShade as **risky** (UEVR compatibility note). The compatibility chip in the module card now appears for any capability with an explicit `compatibilityStatus`, not just a hard-coded list.

## Install (Windows 10 / 11 x64)

Download the installer below and run it. It puts Moddin in `%LOCALAPPDATA%\Programs\Moddin Desktop` and adds an uninstaller to **Settings → Apps**.

- **Installer:** `Moddin.Desktop_0.1.0_x64-setup.exe` (attached below) — 3.6 MB (NSIS, installs per-user, no admin required)
- **SHA-256:** `DDDA8D13DA1742017595F72995736733BC5664DF00B2504901FDAE823147584C`
- WebView2 Runtime is required (pre-installed on Windows 11; Windows 10 installs it automatically if missing).

### Or build from source

If you prefer to compile it yourself, you need `Node.js 20+`, `Rust stable (MSVC)` and the Visual Studio C++ build tools.

```powershell
git clone https://github.com/petonexus/moddin-desktop.git
cd moddin-desktop
git checkout v0.1.0-beta.3
git submodule update --init --recursive
npm ci
npm run tauri build
```

The installer ends up in `src-tauri\target\release\bundle\nsis\`, the standalone exe in `src-tauri\target\release\moddin-desktop.exe`.

## Known limitations

- The Rust `capability_authoring` backend is not in this build yet, so the "Save" button inside the AI dialog will fail. Use the dialog to draft the prompt, then paste it into ChatGPT / Claude / another AI. The UI is ready for the backend; the backend lands in the next release.
- The Collections feature is stubbed. Installing or browsing a collection returns "not yet available".
- Some preview text that comes from the backend (the "what Moddin will do" list) and the recommended VR settings are still in English only.
- GOG games are detected by the backend but do not appear in the library yet.
- OFXR Bridge is **experimental** and may cause artifacts or crashes depending on game, GPU and VR runtime. Every change can be undone from History.
- Anti-cheat is never bypassed.
