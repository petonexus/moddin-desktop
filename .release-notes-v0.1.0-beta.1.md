# Moddin Desktop v0.1.0-beta.1

First public beta. Built for early adopters who want to install mods the safe way: with a preview, a backup transaction, and an Undo that works weeks later.

> ⚠️ This is a **beta**. It runs real installs, real registry writes, and real process kills. Read the [User Guide](https://github.com/petonexus/moddin-desktop/blob/main/docs/USER-GUIDE.md) before clicking Apply on anything new.

### What you can do

- Detect your installed Steam + Epic games and pick the ones Moddin knows.
- See, for each game, the available mod recipes with **prerequisites shown as a checklist** (game present, archive reachable, hash matches, etc).
- Click **Apply** to see the **full preview** of every file and registry key the mod will touch.
- Every install is recorded as a transaction — Moddin can undo it later, even weeks later, by restoring the original files.
- Browse the **community catalog** of capabilities verified by Ed25519 signature (toggle from the **⇆ Community** button in the top dock).

## Install

> ⚠️ **No prebuilt MSI in this release.** The Tauri MSI pipeline is being wired
> to GitHub Actions; in the meantime, build the desktop app from source.
> Steps below assume you have `Node.js 20+`, `Rust stable MSVC`, and
> `cargo-tauri` (`cargo install tauri-cli --version "^2.0"`) on the PATH.

1. Clone the repo and check out `v0.1.0-beta.1`:

   ```powershell
   git clone https://github.com/petonexus/moddin-desktop.git
   cd moddin-desktop
   git checkout v0.1.0-beta.1
   ```

2. Install frontend deps and produce the renderer bundle:

   ```powershell
   npm ci
   npm run build
   ```

3. Build the desktop installer (per-user MSI, no admin required):

   ```powershell
   cargo tauri build --bundles msi
   ```

   The signed-per-user MSI lands at
   `src-tauri\target\release\bundle\msi\Moddin Desktop_0.1.0-beta.1_x64_en-US.msi`.

4. Run the MSI. Moddin installs under `%LOCALAPPDATA%` and auto-scans your
   Steam + Epic libraries on first launch.

### Requirements

- Windows 10 / 11 x64
- ~200 MB free disk space for the app + caches
- WebView2 Runtime (pre-installed on Windows 11; auto-installed on Windows 10 by the MSI when produced)
- Visual C++ Redistributable x64 (pre-installed on Windows 11; auto-installed by OFXR Bridge if you install it)

1. Moddin version (`%LOCALAPPDATA%\Moddin\config\version.json`)
2. Windows version
3. Steps to reproduce
4. Activity log excerpt (`≡` button → filter by error)

## Known limitations

- OFXR Bridge is **experimental**. It may produce artifacts, freezes, or crashes depending on the game, VR mod, GPU and runtime. The activity log records every action for quick rollback.
- Anti-cheat is never bypassed. Moddin requires you to use your own offline / EAC-disabled launch path for games that need it.
- The community catalog is small (1 starter capability). More on the way.
- The **build-catalog** workflow on the community repo has a temporary interop bug that Marco is debugging — until then, sign capabilities locally with the Rust example (`cargo run --example sign_catalog_local`).
